# Security policy

This repository holds two things: the Banking Access Index MCP server (`src/`, published to npm
as `banking-access-index-mcp`) and a skills-only agent plugin (`plugins/banking-access-index/`).
The plugin ships no executable code. Its skill reads two public data files from
www.globalsolo.global.

## Reporting a vulnerability

Email help@globalsolo.global with "security" in the subject line. Please don't open a public
issue for it.

Include the affected version or commit, what you saw, and the steps to reproduce it.

## Supported versions

Fixes go into the latest npm release and the default branch.
